LUVICS CLIMA NO PONTO — pacote de teste local
==============================================

O que e:
  Pagina leve (Leaflet) + backend Flask
  Relatorio GRATIS: temperatura + mapa 1km + CTA R$ 9,90
  Relatorio COMPLETO (simulacao paga): previsao 7d, vento, chuva, historico

Instalar:
  pip install flask requests fpdf2 staticmap pillow

Rodar (na pasta luvics_clima):
  python app.py

Abrir no navegador:
  http://127.0.0.1:5050

Fluxo de teste:
  1. Busque um endereco OU clique no mapa (rural/satelite)
  2. (Opcional) preencha e-mail — ainda NAO envia, so registra no PDF
  3. "Receber relatorio GRATIS" → download PDF incompleto
  4. "Simular relatorio COMPLETO" → download PDF pago

APIs usadas (gratis):
  - Nominatim OpenStreetMap (busca)
  - Open-Meteo (clima)
  - Tiles OSM / Esri (mapa)
