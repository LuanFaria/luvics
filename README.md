# TECH LUVICS 🌍🛰️

Bem-vindo ao repositório oficial da **TECH LUVICS**, uma plataforma dedicada a transformar dados espaciais em oportunidades reais por meio da geotecnologia, QGIS e inteligência aplicada.

---

## 🚀 Sobre o Projeto
Este repositório armazena o código-fonte da landing page e das páginas institucionais da Tech Luvics, oferecendo conteúdos voltados para a capacitação profissional, monetização com geoprocessamento e soluções inovadoras no mercado de geotecnologias.

## 🛠️ Tecnologias Utilizadas
O projeto foi desenvolvido focando em alta performance, design limpo e responsividade, utilizando:
* **HTML5** e **CSS3** (com variáveis customizadas e design system próprio)
* **Google Fonts (Inter)**
* **Design Responsivo** (compatível com desktops, tablets e smartphones)

## 📁 Estrutura do Repositório
* `index.html` - Página principal (Home) da plataforma.
* `IMG/` - Ativos visuais, capas de eBooks, mockups e imagens institucionais.
